5. Changing a technician's type - what is refused

The franchisee admin (home: anyone with technicians.edit) can change technicianType. A change only affects jobs accepted after it (T1, frozen in the accept snapshot) - but task 05/06 add two guards on top. Both are stricter than T1 and need owner confirmation.

An open redemption is already reserved, so it does not count; a negative balance is allowed.
