1. Task 00 - the test harness

The repo had no tests at all; CI only compiled the API and linted the clients. Owner ruling X1: API tests never touch a database - pytest is for pure functions (parsers, calculators, state machines). Database behaviour is proven by each task's acceptance criteria and by api/app/scripts/seed/verify.py. Three runners, three separate configs:

4. Owner decisions

The owner has ruled on ten of the original questions; the mocks show the settled behaviour. Five remain open, each with a written default the code follows until the owner says otherwise (16, end of document).

Still open (5)

  1. Status code for an out-of-range pincodePINCODE_OUTSIDE_FRANCHISEE: 422 everywhere (reconciled); the owner may prefer 400 for the base-location case.
  2. Facility admin and operator share part powersThey have the same part powers; the admin also manages operators (P6).
  3. Franchisee admin sees tickets read-onlyBy ownership, never by territory; a franchisee admin reads its tickets and cannot write (F13).
  4. Employee force-close payoutIgnored, not refused, when a manager force-closes an employee's job.
  5. Reversal month on statementsA reversal lands in the month it is written, not the month of the penalty it reverses.

Settled by the owner (10) shown in the mocks

  1. R1 - Speed clock startThe clock starts at the later of the accept and the confirmed slot start. Accepted Mon 11:00, slot Thu 10:00-12:00, completed Thu 13:00 is 3 working hours, so a reward. Minus Awaiting Part as before; if the slot starts after completion the clock reads 0. See the speed calculator.
  2. R2 - An approved part that can never be suppliedA facility may cancel an approved request: approved → rejected, reason required; the job returns to In Progress once nothing is requested or approved. See the state machine.
  3. R3 - A non-home franchisee with no active adminNo company fallback. Instead the last active admin of a non-home franchisee cannot be deactivated: 409 FRANCHISEE_LAST_ADMIN. The home franchisee is exempt.
  4. R4 - Home-franchisee part requestsNo Admin / NH fallback. Technicians of a franchisee with no active facility admin or operator cannot raise requests (409 NO_FACILITY) and the app says "Your franchisee has no parts desk yet." Company Admin / NH can create facility users for the home franchisee.
  5. R5 - Type-change rulesRefused while the technician holds an open job (TECHNICIAN_HAS_OPEN_JOBS) and freelancer to employee refused while redeemable money remains (TECHNICIAN_HAS_BALANCE).
  6. R6 - vendorPricePaiseWithheld from franchise principals.
  7. R7 - Speed money on force-closeNone.
  8. R8 - What staff see of a non-home jobCompany staff see both the travel amount and the speed outcome on any ticket in their scope, non-home franchisees included; never the base's coordinates or the franchisee's pool. Facility staff and vendors see neither amount.
  9. R9 - Self-set baseA technician may set their own base. The source (Pincode / GPS / Map / Set by admin), who set it and when are shown to the franchisee admin, who can correct it at any time. No approval, no cooldown.
  10. R10 - Travel estimate on the pool offerNot shown.
