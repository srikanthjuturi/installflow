No parts store set up (home franchisee)The technician’s franchisee has no active facility admin or operator, so the server would refuse a request (409 NO_FACILITY) and the app disables Need a spare part and says why. Company Admin and National Head do not stand in; they add a facility admin on Facility users (page 13e).
